# 更多漏斗 / More Hoppers

Fabric 1.21 模组：在原版漏斗基础上新增 **金 / 钻石 / 下界合金 / 铜 / 逆向** 五种漏斗。
所有机制都改写自原版漏斗（放置、朝向、红石禁用、比较器、容器与物品实体交互全部复用原版代码），
所有贴图都由原版材质程序化改写而来。

## 漏斗一览

| 漏斗 | 配方 | 槽位 | 传输速率 | 吞吐 |
|---|---|---|---|---|
| 普通（原版） | — | 5 | 8 游戏刻 / 件 | 2.5 件/秒 |
| 金漏斗 | 工作台：中心 1 漏斗 + 上下左右各 1 金锭 | 5 | 4 游戏刻 / 件 | 5 件/秒 |
| 钻石漏斗 | 工作台：中心 1 漏斗 + 上下左右各 1 钻石 | 5 | 2 游戏刻 / 件 | 10 件/秒 |
| 下界合金漏斗 | 锻造台：钻石漏斗 + 1 下界合金锭（**不需要升级模板**） | 5 | 1 游戏刻 / 件 | 20 件/秒 |
| 铜漏斗 | 工作台：中心 1 漏斗 + 周围 8 格各 1 铜锭 | **10** | 5 游戏刻 / 件 | 4 件/秒 |
| 逆向漏斗 | 工作台：中心 1 漏斗 + 上下左右各 1 红石 | 5 | 5 游戏刻 / 件 | 4 件/秒 |

所有漏斗被红石信号充能时停止传输（与原版一致）。实际吞吐仍受上方容器、下方容器与物品流影响。

## 铜漏斗

- 10 个槽位，界面比原版漏斗多一行。
- **左键点槽位**：切换该槽启用/禁用（与原版合成器同样的操作规则：禁用要求鼠标上没拿着物品）。
- **右键点槽位**：手上拿着物品时把该槽设为"只允许这种物品通过"（白名单，幽灵物品，**不会消耗**物品）；
  空手右键清除该槽白名单。
- 被禁用的槽位既不接受也不输出物品；已经在里面的物品会留在原地（和原版合成器一致）。
- 白名单按**物品类型**匹配，忽略耐久/附魔/数量等组件。

## 逆向漏斗

- 放置方式与朝向和原版漏斗完全一样（贴墙、天花板下都能放），模型上下翻转显示。
- 传输方向与原版镜像：**从下方容器吸出物品，向正上方容器输出**，也能从下方拾取掉落物；
  掉进漏斗自己斗里的物品同样会被吸走（与原版一致，不会卡在漏斗里）。
- 同样受红石信号禁用。

## 构建

```bash
./gradlew build          # 产物在 build/libs/more-hoppers-1.0.0.jar
./gradlew runGameTest    # 10 个 Fabric GameTest（速率、红石、铜漏斗槽位与白名单、逆向漏斗拾取与轮廓、无模板锻造、GUI 画布尺寸）
./gradlew runClient      # 本地试玩
```

需要两端都安装（模组新增了方块与配方）。依赖 Fabric Loader ≥ 0.19.4 与 Fabric API。

## 材质是怎么来的

`tools/make-textures.ps1` 与 `tools/make-models.ps1` 直接从 Fabric Loom 缓存里的原版客户端 jar
读取原始材质与模型，程序化改写后写入 `src/main/resources`：

- 金属漏斗的方块贴图与物品图标 = 原版 hopper 贴图做**离散调色板替换**（像素位置、透明度、
  明暗层级一一保留，只把中性灰换成对应金属色阶；金属主色取自原版金属锭贴图较亮一半的平均色）。
- 逆向漏斗不新建方块贴图，模型直接用原版贴图，上下翻转由 `blockstates` 里的 `"x": 180` 完成。
- 铜漏斗 GUI = 原版 `hopper.png` 插入一行 18px 槽位带（面板 176×151），槽位底纹与边框完全沿用原版。
- 模型 JSON = 原版 `hopper` / `hopper_side` 模型，元素一根线都不改，只替换贴图引用。

两个脚本可以重复执行，产物可复现。
